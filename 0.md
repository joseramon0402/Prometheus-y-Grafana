# 0. Introducción a Prometheus y Grafana

## ¿Qué es Prometheus?

**Prometheus** es una herramienta de monitorización y recopilación de métricas de código abierto que permite supervisar el estado y el rendimiento de servidores, aplicaciones y otros servicios.

Su funcionamiento se basa en recopilar métricas periódicamente de los sistemas monitorizados y almacenarlas en una base de datos de series temporales. Además, permite realizar consultas mediante su propio lenguaje, denominado **PromQL**, para analizar los datos obtenidos.

Entre sus principales características destacan:

- Recopilación automática de métricas.
- Almacenamiento de datos históricos.
- Consultas personalizadas mediante PromQL.
- Sistema de alertas para detectar problemas.
- Integración con diferentes exportadores (*exporters*) para monitorizar distintos servicios y sistemas.

## ¿Qué es Grafana?

**Grafana** es una plataforma de código abierto utilizada para visualizar y analizar métricas procedentes de diferentes fuentes de datos.

Permite crear paneles personalizados (*dashboards*) en los que se representan los datos mediante gráficas, tablas y otros elementos visuales. De esta manera, facilita la interpretación de la información y permite detectar posibles problemas de rendimiento.

Entre sus principales características destacan:

- Creación de paneles de monitorización personalizados.
- Visualización de métricas en tiempo real.
- Integración con diferentes fuentes de datos, como Prometheus.
- Configuración de alertas.
- Representación de datos mediante gráficas y tablas.

## ¿Cómo trabajan conjuntamente Prometheus y Grafana?

Prometheus y Grafana son dos herramientas que se complementan para crear un sistema completo de monitorización.

- **Prometheus** se encarga de recopilar y almacenar las métricas de los servidores y servicios monitorizados.
- **Grafana** utiliza esas métricas como fuente de datos para representarlas gráficamente mediante paneles personalizados.

Gracias a esta combinación, podemos supervisar el estado de varios servidores, analizar su consumo de recursos (CPU, memoria, disco, etc.) y detectar posibles incidencias.

## Objetivo de la práctica

El objetivo de esta práctica es aprender a instalar, configurar y utilizar Prometheus y Grafana para implementar un sistema de monitorización externa.

A lo largo de los siguientes apartados se realizarán las siguientes tareas:

1. Instalación y configuración de Prometheus.
2. Instalación y configuración de Grafana.
3. Integración de Prometheus como fuente de datos en Grafana.
4. Monitorización de varios servidores.
5. Realización de pruebas de estrés para analizar el rendimiento de los servidores.
6. Creación de consultas personalizadas y nuevos paneles de visualización.
7. Configuración de alertas mediante Gmail.
8. Monitorización de bases de datos MariaDB.

Con esta práctica se pretende adquirir conocimientos sobre la monitorización de sistemas, el análisis de métricas y la detección de problemas mediante herramientas especializadas.
