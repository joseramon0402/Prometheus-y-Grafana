# Instalación y configuración de Prometheus y Node Exporter

## 1. Instalación de Yamllint

Instalamos `yamllint`, una herramienta que permite comprobar la sintaxis y detectar errores en archivos de configuración YAML, como el archivo `prometheus.yml`.

**Comando utilizado:**

```bash
sudo apt install yamllint
```

## 2. Configuración de Prometheus

Editamos el archivo de configuración de Prometheus:

```bash
sudo nano /etc/prometheus/prometheus.yml
```

En este archivo configuramos los siguientes parámetros:

- `scrape_interval: 15s`: establece cada cuánto tiempo Prometheus recoge las métricas.
- `evaluation_interval: 15s`: establece cada cuánto tiempo se evalúan las reglas.
- `job_name: prometheus`: identifica el propio servidor Prometheus.
- `localhost:9090`: dirección donde se encuentra Prometheus.
- `job_name: node`: identifica el trabajo encargado de recoger las métricas del equipo.
- `172.26.2.58:9100`: dirección IP y puerto donde está funcionando Node Exporter.

De esta manera, Prometheus puede recoger tanto sus propias métricas como las del equipo monitorizado mediante Node Exporter.

## 3. Comprobación de los servicios

Comprobamos que los dos servicios están funcionando correctamente mediante los siguientes comandos:

```bash
systemctl status prometheus
systemctl status prometheus-node-exporter
```

En la salida podemos observar que ambos servicios aparecen como `active (running)`, lo que significa que están iniciados y funcionando.

## 4. Acceso a la interfaz web de Prometheus

Accedemos a la interfaz web de Prometheus a través del navegador, utilizando el puerto `9090`.

Desde esta interfaz podemos introducir consultas para visualizar las métricas recogidas por el sistema.

## 5. Comprobación de los Targets

Desde el apartado **Status → Targets** comprobamos que Prometheus está recogiendo información de los objetivos configurados.

Podemos observar dos objetivos:

- **node:** corresponde a Node Exporter, que recoge las métricas del equipo.
- **prometheus:** corresponde al propio servidor Prometheus.

Ambos aparecen en estado `UP`, lo que indica que Prometheus puede comunicarse correctamente con ellos y recoger sus métricas.

## 6. Comprobación de Node Exporter

Accedemos a Node Exporter mediante el puerto `9100`.

En su página principal podemos encontrar el apartado **Metrics**, donde se muestran las métricas que Node Exporter obtiene del equipo, como información de CPU, memoria, disco y otros recursos del sistema.
